# Assets

Every file under `textures/` is from [Poly Haven](https://polyhaven.com) and is in the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Each set is the 1k JPEG download of one asset, renamed: `color.jpg` is its diffuse map, `normal.jpg` its OpenGL normal map, `rough.jpg` its roughness map.

| Set | Asset | Source |
|---|---|---|
| `asphalt` | Asphalt 02 | https://polyhaven.com/a/asphalt_02 |
| `concrete` | Concrete Floor 02 | https://polyhaven.com/a/concrete_floor_02 |
| `container` | Container Side | https://polyhaven.com/a/container_side |
| `corrugated` | Corrugated Iron 02 | https://polyhaven.com/a/corrugated_iron_02 |
| `planks` | Wood Planks | https://polyhaven.com/a/wood_planks |
| `plywood` | Plywood | https://polyhaven.com/a/plywood |

Downloaded on 2026-11-12 from `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/<asset>/<asset>_{diff,nor_gl,rough}_1k.jpg`.

Everything else in the yard, the truck included, is modelled in code from boxes and cylinders, and the sky is a shader.
